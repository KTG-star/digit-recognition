# Task 5: Handwritten Digit Recognition

This application uses a **Convolutional Neural Network (CNN)** to identify handwritten digits. 

### Why this is Efficient:
- **Spatial Invariance:** Recognizes digits regardless of where they are drawn.
- **Normalization:** Automatically scales and centers input to match MNIST standards.
- **Robustness:** Trained with Dropout layers to handle messy or unconventional handwriting.
